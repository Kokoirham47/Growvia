# DESIGN.md — Growvia Design System

## 1. Tokens & Color Palette
- **Deep Navy (Brand Primary):** `#1E3A8A`
- **Royal Blue (Accent & CTAs):** `#2563EB`
- **Dark Slate (Main Text):** `#1E293B`
- **Secondary Slate:** `#64748B`
- **Muted Slate:** `#94A3B8`
- **Canvas / Background:** `#F8FAFC`
- **Card Surface:** `#FFFFFF`
- **Card Border:** `#E2E8F0` / `#E8ECF2`
- **AI Primary (Indigo):** `#6366F1`
- **AI Surface (Soft Indigo):** `#EEF2FF`
- **AI Border:** `#E0E7FF`
- **Success / Validated:** Text `#15803D`, BG `#DCFCE7`, Accent `#16A34A`
- **Warning / Develop:** Text `#B45309`, BG `#FEF3C7`, Accent `#F59E0B`
- **Danger / Missing:** Text `#DC2626`, BG `#FEE2E2`, Accent `#EF4444`

## 2. Typography
- **Primary Font:** Poppins, Inter, system sans-serif.
- **Hierarchy:**
  - H1 Hero: 32px / 2rem, 700 weight, `#1E293B`
  - Section Headings: 20px / 1.25rem, 700 weight, `#1E293B`
  - Card Titles: 16px / 1rem, 600 weight
  - Body Copy: 14px / 0.875rem, 400 weight, `#64748B`
  - Badges / Sub-labels: 11px–12px, 500–600 weight

## 3. Elevation & Surfaces
- Clean, crisp card borders (`1px solid #E2E8F0` or `#F1F5F9`) with subtle elevation (`0 1px 3px rgba(15,23,42,0.04)`).
- Border radius: `16px` for primary cards, `12px` for nested inner containers and buttons, `9999px` for badges/pills.
